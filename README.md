# Simple Java Calculator 🧮

A console-based calculator built in Java to practice core programming logic and input handling.

## 🛠️ Tech Stack & Concepts
* **Language:** Java
* **Libraries:** `java.util.Scanner`, `java.util.Locale`
* **Concepts:** Switch statements, basic math logic, and error handling.

## 💡 What it does
1. Reads two numbers and an operator (`+`, `-`, `*`, `/`) from the console.
2. Formats decimals with US standards (`.` instead of `,`).
3. Handles edge cases:
   * Prevents **division by zero**.
   * Identifies **unknown operations**.
